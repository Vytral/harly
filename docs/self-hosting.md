# Self-hosting Harly

The maintained self-hosting guide lives on the Harly documentation site. This
page is kept only so existing repository links keep working; it is not a second
copy and is not updated separately.

- [Self-hosting overview](../apps/docs/self-hosting/overview.mdx): topology,
  VPS requirements, DNS, ports, and resource profiles.
- [Proxy modes](../apps/docs/self-hosting/proxy-modes.mdx): Caddy, external
  reverse proxy, and local loopback modes.
- [Operations](../apps/docs/self-hosting/operations.mdx): health checks, the
  scheduler runbook, backup, restore, upgrade, and the development database.
- [Install with the CLI](../apps/docs/deployment/cli.mdx): the guided installer
  and management menu.
- [Cloud deployments](../apps/docs/deployment/cloud.mdx): managed platforms and
  the S3-compatible storage requirement; see also [cloud-deployments.md](cloud-deployments.md).
- [Configuration](../apps/docs/deployment/configuration.mdx): environment
  variables. The short reference is [configuration.md](configuration.md).
