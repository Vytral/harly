# Archived engineering notes

The files in this folder are historical engineering notes: audits, diagnoses,
baselines and rollout plans written while the automations and AI-assistant
features were being built. They record what the team knew and decided on the
date in each file name.

They are kept for traceability. They are not product documentation and they
are not kept current. Statements such as "pending", "blocked" or "not yet
implemented" describe the state on that date and may no longer be true.

For the current state, use:

- [ROADMAP.md](../../ROADMAP.md) for product direction and status.
- [Automations](../../apps/docs/developers/automations.mdx) for the public
  automations behavior, including the withdrawn public REST API.
- [AI Copilot roadmap](../ai-copilot-roadmap.md) for the focused AI plan.
- [Automations product plan](../automations-product-plan.md) for the
  automations plan and package history.

Evidence files referenced by some notes (for example
`audit-evidence/…`) were never committed to this repository.
