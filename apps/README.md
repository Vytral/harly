# Harly Apps

This directory contains deployable applications.

## Current apps

- `web`: the current Harly core product app. It is the self-hostable ATS and
  the future cloud-hosted app codebase.
- `marketing`: placeholder for `harly.dev`.
- `docs`: placeholder for `docs.harly.dev`; expected to move to its own repo
  once the public docs stack is selected.

## Direction

Keep product, marketing, and docs independent. The core app should remain
self-hostable and cloud-hostable from the same codebase.
