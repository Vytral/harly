Harly is an open-source applicant tracking system you can host yourself. Use it
to publish jobs, review applications, schedule interviews, and send offers. Your
team works from the same candidate record throughout the hire.

## What you need to run Harly

The standard Docker Compose installation runs a web app, a scheduler, and
PostgreSQL. It stores uploads locally by default. The bundled Caddy proxy can
handle HTTPS, or you can use an [existing reverse proxy](/self-hosting/proxy-modes).
For managed services, see [cloud deployments](/deployment/cloud).

You can start reviewing applications without connecting a mail service or an
AI provider. When you need one, [connect it in your workspace](/integrations/overview).
To build against Harly, start with the [REST API](/developers/api-overview) or
[connect an MCP client](/developers/mcp).

Harly is MIT-licensed. The [source code and releases are on GitHub](https://github.com/vytral/harly).
