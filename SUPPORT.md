# Getting help

Harly is a community project with no paid support or SLA. These are the places
to go, in order:

1. **[Documentation](https://docs.harly.dev)**, including installation,
   configuration, troubleshooting and the API reference.
2. **`harly doctor`** on your server, which checks the installation and
   explains what is wrong.
3. **[Discussions → Q&A](https://github.com/Vytral/harly/discussions/categories/q-a)**
   for setup questions, how-to questions and anything you are not sure is a bug.
4. **[Issues](https://github.com/Vytral/harly/issues/new/choose)** for
   reproducible bugs and agreed improvements.

Security vulnerabilities are reported privately, never in public. See
[SECURITY.md](SECURITY.md).

When you ask for help, include your Harly version, how you deploy it, and the
output of `harly doctor`, with secrets and candidate data removed.
