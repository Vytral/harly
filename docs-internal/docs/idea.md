# Harly Docs — Idea

## What is this?

The public documentation site at docs.harly.dev. Covers everything a self-hoster or
cloud user needs to know: setup, configuration, deployment, customization, upgrading,
and contributing.

## Who is it for?

- Developers setting up Harly for the first time
- Self-hosters troubleshooting their deployment
- Contributors who want to understand the codebase
- Anyone evaluating Harly who wants to understand how it works before committing

## Problem

Most open-source projects have terrible docs. A README with 5 lines and a broken
screenshot. Great docs are a competitive advantage — they reduce support burden, increase
adoption, and signal project maturity.

## Differentiation

- Every guide is tested against a real deployment (not just written from memory)
- Guides for specific platforms: Railway, Fly.io, VPS — not just generic instructions
- Troubleshooting sections with common errors and fixes
- "What's new" section per version

## Non-goals

- Not an API reference in v1 (no public API yet)
- Not a developer guide to the internals (contributing guide covers the basics)
- Does not need i18n in v1

## Success criteria

- A developer with basic Next.js knowledge can self-host Harly in under 10 minutes
  following only the docs
- Support requests that could be answered by the docs drop over time
- Docs site indexed by Google for "self-hosted ATS" queries
