# Harly Marketing — Idea

## What is this?

The public website at harly.dev. A standalone app (or site) whose only job is to
make someone who lands on it understand what Harly is, want to use it, and take
action — either self-hosting or joining the cloud waitlist.

## Who is it for?

Anyone who discovers Harly for the first time via:
- Product Hunt
- Hacker News
- GitHub (links back to harly.dev)
- Google ("open source ATS self-hosted")
- Twitter / X

## Problem

A great product with a bad landing page dies in obscurity. The marketing site is the
first impression. It needs to answer three questions in under 10 seconds:

1. What is this?
2. Why should I care?
3. How do I get it?

## Differentiation

The site itself should feel like the product — modern, clean, fast. If the landing page
looks like a 2015 WordPress blog, no one will trust the ATS.

Design references: cal.com, trigger.dev, formbricks.com — open-source projects that
nail the marketing site.

## Non-goals

- Not a blog (no CMS needed in v1)
- Not a docs site (that's docs.harly.dev)
- Not a dashboard (no auth, no user state)
- Does not need to be multilingual in v1

## Success criteria

- Bounce rate < 60%
- Average time on page > 45 seconds
- Clear CTA conversion: GitHub stars + waitlist signups
- Passes "would I star this on GitHub after seeing this site?" test
