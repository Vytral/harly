1. SCIM 2.0
     Provisionamiento y desprovisionamiento automático de usuarios desde Okta, Azure AD o Google Workspace.

  2. Gestión de sesiones y dispositivos
     Ver sesiones activas, IP, navegador, último acceso y revocar sesiones remotamente.

  3. Gestión avanzada de miembros
     UI para departamento, región, equipos, manager, estado y asignación automática de roles.

  4. Políticas de aprobación — base implementada
     Requerir aprobación para publicar jobs, cambiar etapas críticas, enviar ofertas o eliminar candidatos.

  5. Audit log empresarial — implementado
     Exportación CSV/JSON, filtros avanzados, retención configurable y envío a SIEM.

  6. Retención y compliance — implementado
     Políticas automáticas de eliminación, legal hold, DSAR completo y reportes de consentimiento.

  7. Observabilidad — implementado
     Métricas, trazas, errores centralizados, alertas de jobs fallidos, latencia SSE y estado de integraciones.

  8. Disaster recovery — implementado
     Restore automatizado probado, RPO/RTO documentados y backups versionados de base de datos y archivos.

  9. API pública empresarial — implementado
     API keys por workspace, scopes, rotación, expiración, rate limits, idempotencia y documentación OpenAPI.

  10. Webhooks robustos — implementado
     Firma HMAC, reintentos exponenciales, replay manual, historial de entregas y dead-letter queue.

  11. Automatizaciones/workflows
     “Cuando ocurre X, ejecutar Y”: cambiar etapa, enviar email, crear tarea, notificar Slack, etc.

  12. Analytics y reporting avanzado — implementado
     Funnel de contratación, time-to-hire, source of hire, SLA por etapa, diversidad y reportes programados.

  13. Seguridad avanzada — implementado
     IP allowlist, dominios permitidos, bloqueo de sesiones sospechosas, reautenticación para acciones sensibles y soporte futuro para passkeys obligatorias.

  14. Multi-tenant/cloud readiness
     límites por tenant, aislamiento reforzado, feature flags, billing, cuotas y migración a workers separados cuando el volumen lo requiera.
